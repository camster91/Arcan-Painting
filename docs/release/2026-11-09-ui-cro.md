# Responsive UI and enquiry improvements — 9 November 2026

Prepared against main revision `70f09a5` after the live visual review. These are source changes for review, not a production release.

## Implemented

- Equal, shrinkable hero grid tracks prevent tablet copy from squeezing project photography into a narrow strip.
- Compact navigation now extends through 1200px; its focus-management breakpoint matches CSS. Desktop labels stay on one line.
- Mobile homepage spacing brings photography forward while retaining the offer, estimate action and review proof.
- Contact has one compact introduction and a form anchor, rather than two introductory sections.
- Only the selected response method's contact field is visible/enabled. Other field values remain in the component when switching methods; inactive inputs are excluded from validation and submission.
- Scope, requested estimate timing and budget use a native optional-details disclosure. Scope defaults to “To be discussed,” not an assumed complete residence. Entered optional values survive closing the disclosure.
- Contact/service mobile actions focus and scroll to the enquiry field rather than reloading the contact page. The fixed bar hides while form fields have focus.
- Project slider cards link to a validated specific gallery photo. Collection links preserve the service category. The gallery opens the selected photograph and restores focus to its scene cover on close.
- Gallery enquiries carry only an allowlisted public photo key, select its service and include its public reference in the request body. Unknown project keys are ignored. Personal contact details remain out of URLs and analytics.
- Existing attributed review text appears beside the contact flow. Interior scope and portfolio introduction use clearer buyer-facing copy without adding insurance, warranty, response-time or other unverified claims.
